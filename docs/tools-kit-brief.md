# TypeStax — Tools Kit Brief

**TypeStax**
*A type scale generator that feels like vintage audio hardware.*
[typestax.vercel.app](https://typestax.vercel.app)

TypeStax is a type scale builder for designers working on design systems. You set a base size and a ratio, and it gives you a full, balanced scale that you can fine-tune per element and export ready to use. The whole thing runs on a dark analog control panel with rotary dials, backlit amber displays and VU meters.

## What it does

- **Scales:** eight musical ratios, from Minor Second (1.067) to Golden Ratio (1.618), or a custom ratio. It covers display 1–3, h1–h6, body, eyebrow and small.
- **Per-element control:** override size, weight, line height and letter spacing for any element. Heading weights can auto-balance.
- **Fonts:** the full Google Fonts library, with real metrics read from the font files.
- **Presets:** 63 curated heading and body pairings in 11 moods, including editorial, tech, minimal, luxury and literary.
- **Live previews:** see the scale in website, blog, dashboard and style-card templates, in desktop, tablet and mobile frames.
- **Exports:** CSS, Tailwind (v4 CSS and v3 config), Figma tokens (JSON or pushed straight into a file), and Pencil `.pen` libraries. You can also copy the CSS for a single element.
- **Sharing:** undo and redo, shareable URLs, and a gallery of saved stacks.

**Tags:** typography · type scale · design systems · design tokens · Figma · Tailwind · Google Fonts

## Short version

> TypeStax: build balanced type scales on an analog synth-style control panel. Pick fonts and a ratio, tweak each element, preview it in real layouts, and export to CSS, Tailwind, Figma or Pencil.
